# 연결 증거 등록·종료·복구 검사

`python3 Tests/checks/forwarding-evidence-lifecycle/run.py NODE_REPO EVIDENCE_DIRECTORY`

실제 Swift 런타임·중계·참여자 등록부·전환 조정자와 정확한 Node 099dcd8의 권한 원장·비공개 제어 파이프를 실행한다. HTTP는 임의 루프백 포트의 검사 전용 인증 조회다. 실제 Sill 호스트, 운영 포트, 기기, HAL, 음성 제공자는 실행하지 않는다. HAL과 센츄리의 보호 증명만 비활성 경계로 대체한다.

- Node의 attach 처리 후 응답을 지연시키고 연결을 종료한다. 이전 권한은 거부되거나 사용할 수 없어야 한다.
- 이전 controller와 검사 worker의 종료 후에만 다른 boot/PID 하나로 복구한다. 현재 인증된 다른 연결을 다시 등록하고 기존 journal·키·기억된 음성 선택을 보존한다.
- 복구 실패는 차단 상태를 유지하고 주기 조회가 추가 자식을 만들지 않아야 한다.
- bootstrap·renew가 비공개 RPC 큐에서 대기할 때 로컬 복귀를 시작한다. 지연된 증거 등록·갱신은 전송되지 않아야 한다.
- 로컬 복귀는 남아 있는 증거를 해제하고 원격 의도가 없는 상태를 확인한다.

모든 입력 해시와 정확한 Node 소스를 기록하고 자체 자식과 임시 입력을 정리한다. 이 결과는 실제 믹서 무음, 화면 보존, 다른 기기의 실제 음성 복구 수용을 대신하지 않는다.
