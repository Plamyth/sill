# Linked Obsidian notes

Run `python3 -B Tests/checks/linked-obsidian-notes/run.py OUTPUT_DIRECTORY` from the repository root. Use a storage-routed development archive for the output directory. Xcode must be installed at `/Applications/Xcode.app`.

The check compiles the production canvas model, store, and relay against Apple's SDK. It uses PencilKit drawings, an isolated application home, and a controlled URL loading boundary. It does not read the user's vault or contact the live relay.

Assertions cover old scene decoding, path and SHA validation, attaching a Markdown source, compare-and-swap writes, typing during a write, conflict and missing-source handling, stale editor and connection responses, scene replacement, overlapping reads, cache refresh, and preservation of ink provenance and layout. The result records source hashes before and after execution.

Block excerpt checks call the production store and authenticated relay through a controlled URLProtocol fixture. They cover explicit ID reuse, marker creation with exact BOM/Unicode/CRLF byte preservation, saved SHA and GET readback, stale CAS, lost responses without duplicate writes, duplicate/deleted markers, simultaneous draft edits, connection/scene switches, cancellation, ordered readback, native selection ranges, and AI-readable scene JSON. The runner builds the existing StreamProtocol destination policy module and typechecks all CanvasBridge production sources against the iOS SDK. It records these commands and the iOS typecheck exit code in `result.json`.

Linked notes keep at most 512 UTF-8 bytes of display text, marked when truncated. The editor keeps the full source. Size-limit checks verify that valid large notes remain restorable and an oversized scene cannot replace the last restorable save. Ordered reads and source binding are checked across editor recovery and polling. Obsolete read failures cannot block a successful save or a newer accepted read. Dirty-state and save acknowledgements use exact UTF-8 bytes, including normalization-only changes. A rejected foreign-node open preserves the healthy editor and its ability to save.

Excerpt eligibility is deliberately conservative: plain paragraphs with an inline ASCII `^block-ID` suffix or no marker. Lists, tables, quotes, headings, code, frontmatter, detached markers, and ambiguous syntax are refused. Documents containing HTML, Obsidian comments, or display math are refused as a whole. Marker creation inserts only the new suffix, submits one conditional PUT, and requires exact GET readback. An uncertain result blocks further writes until an explicit reread. Missing, duplicate, or unsupported source blocks keep their last verified quote and source SHA; they never substitute a whole-note preview. A full quote digest detects changes beyond the bounded display cache without retaining text history. Legacy whole-note cards retain their existing behavior.

These checks do not establish installed iPad UI acceptance, Pencil gesture parity, or recovery of an unsaved draft after the app process exits.
