# Host microphone backend candidate

This unit implements fork kinds 204 control, 205 state, 206 frame, and 207 receipt. It provides the host transport and conditional AUHAL sink. Native microphone capture, AVAudioSession arbitration, client UI, an original-call owner adapter, and physical audio acceptance remain open. The public initializer's `microphoneOwner` defaults to nil. No current client receives a live microphone capability or opens audio through this unit without an injected original-owner grant and a supported retirement contract. The native backend currently refuses before any device query or I/O because its callback quiescence contract is unproved. It is not an implemented working native HAL backend.

`HostLocalOwnerGrant` is a host-local object with synchronous revocation. It binds an opaque destination and capability, authenticated connection identity, source, input generation, committed video epoch, paired fingerprint, original owner, call generation, exact virtual output/input UID and plugin, existing channel mapping, and monotonic expiry. The future original owner must establish that mapping and revoke the object synchronously on call or input change. Neither a process device list nor thread-scoped appendAudio supplies an exact call writer fence. A remote packet, paired name, installed driver, or compile result cannot create authority.

The receiver has off, preparing, active, retiring, and cleanupFailed states. Its finite action table keeps replay outcomes without eviction. It reserves one stop outcome and refuses exhausted actions or lease serials. A stopped preparation still cleans its own returned resource. Cleanup failure retains that resource, closes frame/render admission, and blocks new starts without retry. An old exact stop can retrieve its terminal outcome after the source changes. A stop with nil grantID reconciles the original start requestID, even before start arrives or while preparation or its enabled reply is pending. It records a bounded tombstone before ordinary replay/conflict handling. Later starts with that same ID cannot allocate a sink. On a full ingress queue the same-ID cancellation replaces its pending start. An unmatched overflowing cancellation quarantines and cancels its peer; the queued and later starts cannot reach the receiver. The local `retryCleanup(grantID:)` API retries only the retained resource explicitly. Remote duplicate stop does not trigger a cleanup retry or allocate another effect.

PCM is 48 kHz mono signed 16-bit little endian, with 1 through 960 frames per packet. Its 113-byte binary header has version, format, six UUIDs, a tagged source, sequence, and frame count. The decoder checks lengths before sample storage. Sequence gaps over 4096, replay, mismatched scope/grant, and application queue residence over 60 ms are refused. The application ingress has eight control slots, one latest frame, and one scheduled actor drain before the ordinary per-message Task path. These limits do not bound TCP/OS queues or measure end-to-end latency. Receipts report admission and render counters plus application queue age.

Only currently paired TLS fingerprints on nonsynthetic hosts can reach the microphone path. Pair removal closes its named fingerprint's gate synchronously before asynchronous session teardown. Plain TCP and unpaired TLS cannot grant microphone access. Source changes, same-source pipeline restarts, epoch invalidation, disconnect, owner revocation, expiry, idle ingress, and runtime endpoint changes close admission. Watchdogs begin only after an explicit accepted start. The active response opens sample admission at the fixed NWConnection send boundary under the render and owner gates; a queued response cannot reopen a closed lease.

The output adapter uses public HALOutput with input bus 1 disabled. It resolves the granted output and input UIDs, verifies virtual transport, plugin identity, live state, existing rate and channel counts, sets the owned unit's CurrentDevice, reads it back, and verifies the client format before initialization/start. Its only writes configure that owned unit. It changes no defaults, nominal device rate, device buffers, mute, volume, hog mode, aggregate device, router, or call. An unsupported endpoint or format refuses; it never selects a speaker fallback.

The callback uses preallocated PCM storage, try-locks, and zeros supplied output before reading admitted samples. Owner revocation serializes against render permission. All lease admission and rendering use the same injected monotonic clock. The enabled send accepts serialized bytes and a connection, with no caller-supplied callback under its locks. Native stop, uninitialize and dispose errors retain the exact callback context and unresolved unit. Public stop documentation does not prove callback entry quiescence. Production reports callback quiescence unsupported before resolving a UID or constructing a unit. Its receiver capability is nil even if an original owner is injected. If an explicitly injected test contract later fails to prove quiescence, even successful disposal retains the context and reports cleanupFailed. The callback count is a diagnostic for entered fills, not an entry barrier or a proof that context memory can be freed. The positive quiescence fixture is an inert test-only proof contract. The callback OS/driver contract, physical quiescence, loopback isolation, original-call consumption and actual audible behavior remain unaccepted. No native runtime path was executed by the writer.

## Parent execution

Run only in the parent's approved isolated Mini RAM/SDK environment:

```text
python3 -B Tests/checks/microphone-uplink/run.py ROOT OUTPUT
```

ROOT is this exact accepted Git worktree or separately receipted source. OUTPUT must be outside ROOT. The driver has a 660-second total budget and 90 seconds per child. It compiles a fake Network module, real protocol declarations, the real receiver/grant/ingress/HAL adapter, exact Coordinator/Server/RemoteAccess boundary bodies, and synthetic CoreAudio buffers. All native operations use injected inert C operations; no AudioUnit or device function is executed. It then compiles and executes twelve source mutants. A compile failure never counts as a caught mutant.

The driver writes each command's combined diagnostics, generated fixture files, source and extraction hashes, process/reaping records, assertion count, mutant results, and `result.json`. It prints one `RESULT_JSON` line. On timeout it terminates/reaps the child and saves diagnostics before returning. The parent must preserve these results before RAM cleanup and separately receipt source identity, SDK compilation, independent review, and cleanup. Do not substitute this fixture for whole-product SDK checks. Existing presentation/native-input fixtures remain separate regression gates.

The writer performed Python AST parsing, in-memory fixture generation, unique mutation-anchor checks, source review, and `git diff --check`. Swift compilation, fake runtime, mutants, SDK build, device/audio behavior and original-owner Result acceptance are pending parent execution.
