# Pencil 텍스트 교정 적용 범위

REA에서 실제 Pencil로 관찰한 글자 scratch 삭제, 아래에서 위로 공백 합치기, 위에서 아래로 공백 나누기를 인식된 구조 요소의 편집기에 연결한다. 기본 손글씨 입력은 기존 UIScribbleInteraction이다. 편집기의 펜 교정 전환을 켜면 단일 Pencil 획으로 세 교정 동작을 처리하며 일반 터치는 기존 텍스트 선택·스크롤을 쓴다.

현재 동작 대상은 인식된 노드의 편집 가능한 텍스트다. 원본 PKDrawing과 sourceStrokeIds는 보존한다. 원시 필기에서 글자별 획을 자동 정렬·재배치하는 기능을 구현한 것으로 설명하지 않는다. 한글 등 언어별 OS 손글씨 입력 지원과 실제 Pencil 센서 응답은 실기기 사람 입력으로 별도 수용해야 한다.

애매한 획·편집 도중 바뀐 입력·만료된 편집 세션·조합 중 입력은 적용하지 않는다. 한 줄의 연속된 실제 글자 범위만 삭제한다. 공백에 붙은 결합문자는 일반 공백으로 지우지 않는다. 확정은 기존 Store의 원본 노드 기대 상태·UTF8 동일성 검증을 통과해야 하며 같은 scene revision·JSON·Markdown·PNG 저장 경로를 사용한다. 별도 동기화 원장을 만들지 않는다.

검증은 순수 모델, 실제 UIKit 글자 위치와 Store 저장·재열기, 격리 Obsidian 왕복, 실제 Pencil 센서를 각각 구분한다. 합성 trace나 터치 자동화를 실제 Pencil 입력으로 표시하지 않는다.
