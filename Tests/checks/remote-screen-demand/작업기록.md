## API

`RemoteScreenDemandObservation`과 중첩 타입은 memberwise initializer를 제공한다.
`Source`, `Window`, `Display`, `Epoch`는 Sendable·Equatable이다.
`request(now:)`는 전송 직전 호출하며 revision 0만 throw한다.
만료·잘못된 시각·소스 범위·문자열 길이·목록 초과·중복 incarnation·프레임 초과는 확인 가능한 항목만 남기고 complete=false를 반환한다.
`observedAt`·`expiresAt`·주입 clock은 모두 systemUptime 단위를 사용한다.
TTL은 이 관측의 5000ms 수명에만 적용한다.

`@MainActor RemoteScreenDemandPublisher.init()`, `submit(_:)`, `stop()`을 제공한다.
테스트는 같은 initializer의 clock·open 인자를 주입한다.
첫 submit의 hostGeneration을 인스턴스 수명 동안 고정하고 revision은 submit 수신 순서대로 증가해야 한다.
stop은 종단 동작이다. 새 관측 수명에는 새 publisher를 만든다.
한 건을 전송하면서 가장 최신 관측 한 건만 대기한다.
실패한 관측을 자동 재전송하지 않으며 새 revision의 명시적 submit만 새 시도가 된다.
진행 중 들어온 최신 submit도 명시적 새 이벤트로 처리한다.
같은 소켓의 첫 ACK에서 Core 세대를 고정하고 후속 ACK의 불일치는 소켓을 폐기한다.
