# CCR Sill iPad: REA 조사·기능 복각·Obsidian 파일 연동 완료 목표

원담당 대화: 01a13ace-e372-7ed1-9946-149df37ee1c3
사용자 최신 원문: “싹다 완료할때까지 진행해라. 목표 프롬프트로 만든 후 작업 재개해. 단순 반복 작업이나 단순 루프는 안된다.”

## 최종 결과
MyScript Notes iPad와 MarginNote iPad 및 기존 MarginNote Mac 조사 근거를 기능별로 끝까지 조사하고, 그 사용자 기능을 CCR Sill iPad의 기존 그림판에 구현한다. Pencil·터치에 맞게 편집한 결과를 사람과 AI가 함께 읽고 고칠 수 있는 Obsidian 원본 데이터에 반영한다. 별도 노트 제품이나 기능별 앱을 늘리지 않는다.

그림·문서의 보관 원본을 앱마다 독립된 sandbox에 가두지 않는다. 원본은 Obsidian 보관함 또는 사용자가 파일 앱에서 선택한 iPad 공용 작업 폴더에 둔다. 앱 내부에는 재생성 가능한 캐시와 미동기화 변경의 안전 복구본만 허용하고 상태를 분명히 표시한다. iPadOS가 제공하는 document picker·security-scoped URL·파일 조정을 재사용하며 임의 전역 파일 접근 권한은 만들지 않는다. 앱 삭제로 사라지는 앱 전용 Documents 폴더를 공용 저장 완료로 표시하지 않는다.

## 기능 범위와 증거
문서/서재/페이지, 펜·형광펜·부분/획 지우개·올가미·자, 실제 Pencil 글자 지우기·합치기·나누기·교정·변환, 도형·연결선·수식, PDF/EPUB 읽기·발췌·원문 앵커, 카드·부모자식/링크/병합/정렬/검색·태그·복습, 가져오기·내보내기·공유·오프라인·동기화·충돌/복구, 원앱 AI/OCR 진입과 실제 제공 행동을 누락 없이 기능 원장으로 관리한다. 원앱에 없는 기능을 있다고 추정하지 않는다. 닫힌 엔진·포맷을 완전 해독했다고 꾸미거나 문자열/메뉴를 실행 증거로 대체하지 않는다.

기능별로 원앱 버전과 입력→결과→저장→재열기→취소/실패를 기록하고, REA Evidence/실행 영수증, CCR 구현 경로, 자동 검사, 정확한 통합/설치 버전, 최종 실기기 수용을 별도 열로 둔다. 미확인은 미확인으로 유지한다. 전체 완료는 필수 기능의 조사·구현·Obsidian 저장/재열기/역방향 수정·실기기 검증이 모두 닫혔을 때만 가능하다.

## 실행
Pstack이 상위 목표·계획·분해·상태·검증·독립검수·완료 판단을 맡는다. Ponytail은 구현 단계에서 기존 코드→표준 라이브러리→Apple 기본 기능→기존 의존성→최소 새 코드 순으로 적용한다. 저장/동기화는 데이터 손실 위험 때문에 강화 검증한다.

기준은 공식 integration/ccr-ipad c03d9c2de9eb39cfd50501a73a060a0a34375c8c/tree a912b7d899ebf6bfbc08311461082165f630c2c0이다. 원격 이동 여부를 통합 직전에 다시 읽는다. 독립 변경은 별도 worktree에서 병렬로 하고 같은 파일·기기·Mac UI·음성·보관함 쓰기만 짧게 직렬화한다. 완료된 검수 단위는 커밋→공식 통합→기존 승인 테스트 경로 반영·readback으로 수렴한다. 소스/빌드/설치/실기기/사람 수용을 혼동하지 않는다.

같은 조건의 재조회·재실행·무의미한 heartbeat·단순 프롬프트 루프를 만들지 않는다. 매 단위는 구체적인 누락 또는 결함을 닫고 증거를 남긴다. 같은 미변경 실패가 두 번이면 원인을 바꾸거나 해당 경로만 중단하고 독립 가능한 일을 진행한다. 순정 Codex Goal·ARENA는 사용하지 않는다.

새 진단 앱 설치·기존 앱 삭제·앱별 원본 이동/삭제를 자동 진행하지 않는다. 정상 앱 com.ambrion.sillcanvas.ipad 및 기존 키/권한/그림/문서/초안을 보존한다. 기존 사용자 연결·미디어를 빼앗지 않고 실기기/공유 Mac UI는 현재 소유자와 조율한다. Pencil 센서 입력이 필요한 항목은 구현·자동검사를 마친 최종 정확 빌드에서 한 묶음만 요청한다. 새 네트워크/인증·키·권한·결제·외부 효과 경계는 유지한다.

## 현재 첫 작업
1. 기존 REA 원장·실행·패키지 근거를 실제 기능별 누락표로 수렴한다.
2. 사용자 선택 공용 작업 폴더의 생성/열기/자동 저장·재열기·권한 상실·외부 수정·충돌 보호를 기존 그림판에 구현한다.
3. 원앱에서 확인됐지만 CCR에 빠진 다음 행동을 독립 구현하고 실제 Obsidian 파일 왕복을 검증한다.
4. 기기 조사가 열리면 원앱 자체 시험 문서로 남은 흐름을 재현한다. 대기 중에는 구현·단위·SDK·독립검수를 계속한다.
