# 보호 복구 후 자동 모니터 선택

자동 모니터 선택은 `WindowList.sourceSelectionAdmission` 버전 1을 제공하는 호스트에서 동작한다. 신호가 없거나 유효하지 않거나 `ready == false`이면 자동 요청과 입력 해제를 시작하지 않는다. 명시적 수동 선택에는 기존 호스트의 인증·선택 조건을 적용한다.

같은 연결·Mac·호스트 실행·최초 선택 CAS·모니터 목록 안에서, 미확인 자동 선택을 새 허용 세대마다 한 번 재개한다. 중간 불가 목록을 받지 못했어도 더 높은 세대를 구분한다. 같은 세대 반복, 역행과 같은 세대의 상충 값은 재제출 근거가 아니다. 원래 목표 모니터를 유지하며 수동 선택이나 연결 교체가 자동 의도를 되살리지 않는다.

배포는 공통 DTO와 각 기기 소비 코드의 검수를 마친 뒤 준비 신호를 제공하는 호스트부터 반영한다. 준비 신호가 없는 이전 호스트에서 새 앱의 자동 진입을 보장하지 않는다. 소스·계약 검사와 visionOS 빌드는 실제 원격 영상·시선·통화·오디오·로컬 복귀 수용과 구분한다.
